# 진스 도장

목둘레로 허리둘레를 맞히는 선형회귀 코드 수행평가용 빈칸 훈련이다. `jeans.csv`의 `neck`을 입력, `waist`를 정답으로 두고 `LinearRegression`을 학습하는 코드를, 한글 설명만 보고 채운다.

## 연습 방법

1. **줄마다 해설**에서 코드를 읽고, 가리기 모드로 외운다.
2. **단계 훈련**에서 빈칸을 채운다. 틀린 칸은 목/허리를 바꿨는지, 밑줄이 빠졌는지, 순서가 다른지 바로 알려 준다.
3. **실전 빈칸지**는 시험지처럼 코드 한 장에 칸이 뚫려 있다.
4. **모의고사**는 힌트 없이 한 번씩이다.
5. **함정 10개**는 순서, 30%, 파란 점, 밑줄을 고르는 짧은 확인이다.

띄어쓰기와 따옴표 종류는 정답으로 쳐 준다. 대소문자와 밑줄은 그대로 맞아야 한다. 진도는 브라우저에만 저장된다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:43123](http://127.0.0.1:43123) 에서 연다.

채점 규칙은 `npm test`로 확인한다.
